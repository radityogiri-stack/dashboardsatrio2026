Sinkronisasi Otomatis dengan Google Sheets

Setiap kali Anda mengedit atau menambah data baru di Google Sheets, Web Monitoring ini akan otomatis memperbarui grafik dan metriknya tanpa perlu refresh halaman.

1 Cara Memasang Script di Google Sheets

  1. Buka Google Sheets data Anda di Google Drive.
  2. Klik menu Extensions (Ekstensi) → Apps Script.
  3. Salin script dari file Code_Dashboard_Sync.gs yang sudah disiapkan.
  4. Klik tombol Deploy (kanan atas) → New deployment.
  5. Pilih tipe Web app, atur Who has access ke Anyone.
  6. Salin URL Web App yang dihasilkan, lalu masukkan ke kolom di sebelah kanan.

2 Pengaturan Koneksi Web App

Konfigurasi Sinkronisasi Google Sheets

Masukkan link Google Apps Script Web App dari Google Sheets Anda untuk mengaktifkan pembaruan data secara langsung (real-time).
